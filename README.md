# YtTV – YouTube TV cho Android TV 4.4.4

## Cách lấy APK (không cần Android Studio)
1. Tạo repo mới trên GitHub, upload toàn bộ thư mục này (nhớ cả thư mục .github).
2. Vào tab Actions -> chạy "Build APK" (tự chạy khi push).
3. Tải artifact "YtTV-apk" -> giải nén -> app-debug.apk.
4. Chép vào USB, cài trên TV (bật "Nguồn không xác định").

## Hoặc dùng Android Studio
Mở thư mục -> Build > Build APK(s).

## Đăng nhập
Google chặn đăng nhập email/mật khẩu trong WebView. Trên màn hình YouTube TV
chọn "Đăng nhập" -> hiện mã TV -> mở youtube.com/activate trên điện thoại
và nhập mã. Cách này không bị chặn.

## Phím remote
D-pad/OK: điều hướng | Back: quay lại (bấm 2 lần nhanh để thoát)
Menu: tải lại trang | Play/Pause/Tua: điều khiển video
